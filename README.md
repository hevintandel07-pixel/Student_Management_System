# Smart Student Management & Performance Analytics System

A Python-based web application developed using **Flask** for managing student records, marks, attendance and performing student performance analytics.

## 📌 Project Overview

The Smart Student Management & Performance Analytics System provides a centralized platform to manage student information and analyze academic performance.

The system combines Python programming, database management, data analysis, visualization and machine learning into a single web application.

## 🚀 Features

- Student record management
- Add, search, edit and delete students
- Student marks management
- Automatic total and percentage calculation
- Grade and Pass/Fail calculation
- Attendance management
- Club membership and permission management
- CSV export
- Text file export
- Pickle backup
- Statistical data analysis
- Performance visualization
- Subject correlation analysis
- One-sample t-test
- Random sampling
- Machine Learning based Pass/Fail prediction
- Flask web application architecture

## 📊 Data Science Components

The project integrates multiple Python Data Science concepts:

### NumPy
Used for numerical calculations such as average, maximum and minimum performance values.

### Pandas
Used to create and process DataFrames for student performance analysis.

### SciPy
Used for statistical calculations including:

- Standard deviation
- Variance
- Skewness
- Kurtosis
- Confidence interval
- One-sample t-test

### Matplotlib
Used to create student performance charts.

### Seaborn
Used for subject correlation visualization.

### Scikit-learn
Used to build a Decision Tree Machine Learning model for Pass/Fail prediction.

## 🗄️ Database

The application uses **SQLite** to store:

- Student information
- Marks
- Attendance
- Club membership
- Permission information

The database is automatically created when the application starts.
