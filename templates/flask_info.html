🌐 Flask Web Application

Flask is the web framework used to build the complete Student Management System.

🐍 Python Backend

Flask connects the Python backend with the web interface.

🧩 Routing

Flask routes connect URLs with Python functions.

Example: /students, /marks, /analytics

🎨 Jinja2 Templates

Python data is passed to HTML pages using Flask templates.

🗄️ Database Integration

Flask handles application requests that interact with the SQLite database.

📨 HTTP Requests

GET and POST requests are handled using Flask's request system.

📤 Response & File Handling

Flask renders pages, redirects users and provides downloadable files.
